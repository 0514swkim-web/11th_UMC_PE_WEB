# UMC Web Frontend

UMC 웹 파트 워크북 프론트엔드 실습·미션 기록입니다.

## 기술 스택
- HTML, CSS, JavaScript, TypeScript
- React + Vite, TanStack Router, Tailwind CSS
- Zustand, TanStack Query, ky
- 패키지 매니저: pnpm
